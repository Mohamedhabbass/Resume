# Mohamed Hifzallaa — Portfolio Website

A static, responsive one-page portfolio built from the supplied CV.

## Files
- `index.html` — website
- `style.css` — design and responsive layout
- `resume.pdf` — place Mohamed Hifzallaa's PDF CV here

## Preview locally
Open `index.html` in a browser. For the Download CV button to work, keep `resume.pdf` in the same folder.

## Publish
This is a static site and can be published on GitHub Pages, Netlify, Vercel, or another static hosting service.

After publishing, use the public website URL as the destination for the QR code.
